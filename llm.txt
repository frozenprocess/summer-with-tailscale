# Summer with Tailscale

> A hands-on, numbered series of examples for programmatically provisioning Tailscale networks (tailnets), embedding Zero-Trust networking into application binaries via `tsnet`, and automating cross-tailnet resource sharing through policy-as-code.

This repo is a walkthrough-style collection, not a single deployable app. Each top-level `NN-*` directory is a self-contained module with its own `readme.md`; later modules build on concepts from earlier ones. Code examples are Go; sandbox provisioning is done with `curl`/`jq` against the Tailscale API.

## Prerequisites

- A Tailscale account with API access (OAuth client ID/secret; see `.env.example`)
- Docker or Go, for building/running the `tsnet` examples
- `curl` and `jq` installed locally, for the API walkthroughs

## Modules

- [01-tailnet-sandboxes](01-tailnet-sandboxes/readme.md): Manual curl/jq walkthrough for programmatically creating, listing, and deleting isolated tailnets via the Tailscale Console API (OAuth client credentials flow). Includes a screenshot of the OAuth client setup.
- [02-tailnet-membership](02-tailnet-membership/readme.md): A Go app (`main.go`) using `tsnet` to embed a Tailscale node directly in-process — no system daemon required. Registers on a tailnet, listens with automatic HTTPS via `ListenTLS`, and reverse-proxies traffic to a local backend (e.g. Ollama). Includes a multi-stage `dockerfile` producing a minimal static `scratch`-based image.
- [03-declarative-sharing](03-declarative-sharing/readme.md): Explains Declarative Tailnet Sharing (currently waitlisted) — defining cross-tailnet access as code in the policy file via `externalTailnets` and `grants`, scoped by group/tag rather than raw IPs.
- [04-api-is-the-way](04-api-is-the-way/readme.md): Planned final module tying everything together — provisioning two isolated tailnets, attaching an app to each, and automating cross-app connectivity end to end. Not yet written.

## Key files

- [readme.md](readme.md): Top-level project overview and prerequisites.
- [.env.example](.env.example): Expected environment variables (`CLIENT_ID`, `CLIENT_SECRET`) for the Tailscale OAuth client used across modules.
- [02-tailnet-membership/main.go](02-tailnet-membership/main.go): Reference `tsnet` implementation — reverse proxy exposed over Tailscale with automatic TLS.
- [02-tailnet-membership/dockerfile](02-tailnet-membership/dockerfile): Multi-stage build producing a static Go binary in a `scratch` image, with CA certs bundled for tsnet's HTTPS calls to Tailscale's control plane.

## Notes for LLMs working in this repo

- Module numbering encodes reading/build order — each module's readme ends with a "What's next" pointer to the following one.
- `02-tailnet-membership` is the only module with runnable code today; `01` and `03` are narrative/API walkthroughs; `04` is a stub.
- Tailscale concepts referenced throughout: tailnet, `tsnet`, auth keys vs. OAuth client credentials, policy files (ACLs/grants/groups), Declarative Tailnet Sharing.
